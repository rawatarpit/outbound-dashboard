🧠 The 7 AI Agents

Each agent is a specialized AI powered by a large language model (LLM). They share a common "harness" that handles context, memory, error handling, and observability — so each agent only writes its core logic.

1 Research Agent

Scrapes the company website, feeds the content to an LLM, and extracts structured data: industry, company size, pain points, buying signals, tech stack, and a fit score (0–100).

scrapeUrl generateStructured Zod schema

2 Qualification Agent

Evaluates research data against the brand profile. Decides if this company is worth pursuing. Outputs: fit_score (0–100), reasoning, confidence (0–1).

assembleContext generateStructured

3 Outreach Agent

Writes a personalized cold email. The agent is given the brand's identity and strict rules to never claim they built the target's product. Outputs: subject + body under 150 words.

buildOutreachPrompt generateStructured

4 Reply Analysis Agent

Reads incoming email replies and classifies them: intent (high/medium/low/negative/unsubscribe/OOO), sentiment, objection detection, meeting requested. Auto-suppresses unsubscribe requests.

intent sentiment suppression

5 Negotiation Agent

Drafts follow-up replies when a prospect shows interest. Only activates if confidence ≥ 0.75 and intent is high/medium. Supports multi-turn conversation until close.

multi-turn follow-up

6 Deep Research Agent

Enhanced research using Playwright browser automation + LLM. Scrapes the full website, then runs a deeper analysis with brand context to produce richer company profiles.

Playwright deep analysis

7 Feedback Agent

Reviews past outcomes (closed won, lost, rejected) and updates the system's learning. Re-ranks brand intents by conversion rate, syncs embeddings to improve future discovery.

conversion_rate re-rank embedding sync

🔍 Discovery — Finding Companies With Buying Signals

Two Discovery Paths Run in Parallel

Every 6 hours, the engine runs both source-driven discovery (5 legacy adapters) and signal-driven discovery (20 adapters) and deduplicates results.

Source-Driven (5 legacy)

Scrapes Reddit, Hacker News, IndieHackers, RemoteOK, and Product Hunt for companies discussing relevant topics. Each post is scored for relevance and urgency against the brand profile.

Signal-Driven (20 adapters)

For each brand intent, an LLM generates search queries targeting specific adapters. Runs in 4 phases: query generation → broad search → filter/validate → extract seeds.

📧 Email — Sending & Receiving

Resend Provider

Uses the Resend API for sending. Each brand has its own API key and sending domain. Supports reply-to headers. Automatically increments domain metrics after each send.

SMTP Provider

Nodemailer with pooled transport per brand (3 connections, 100 max messages, 30-min TTL). Credentials fetched via RPC. Deterministic Message-ID injection for threading.

IMAP Inbox Monitor

Continuous push-based monitoring per brand. Classifies inbound emails: bounce, reply, out-of-office, complaint, unsubscribe. Deduplicates by message_id. Triggers reply analysis agent.

10 Safety Checks Before Every Send

🔌 Circuit breaker (per brand, 3 failures → 7min cooldown)
🏥 Domain health (bounce rate, complaint rate)
📊 Daily/hourly quota check
🆔 Idempotency (SHA-256 message key)
🚫 Suppression list check
📝 Thread validation
🎯 Lead confidence ≥ 0.5
🔞 Brand not paused
✅ Outreach draft exists
⚡ Feature flag (send_enabled)

⚙️ Reliability & Safety Systems

Circuit Breaker

Per-brand circuit breaker stored in circuit_breaker_state table. 3 failures → opens for 7 minutes → half-open → closed on success. Prevents cascading failures when an SMTP server is down.

Domain Health

Graduated thresholds: bounce rate starts at 2% (first 10 sends), scales to 5% (after 20). Complaint rate: 0.1% → 0.3%. Auto-pauses brand when exceeded.

Retry Policy

Max 3 retries per entity. Exponential backoff (60s, 120s, 240s → max 15min). Moves to dead letter table when exhausted. Also max 3 enrichment attempts.

Anti-Spam

Auto-suppress on unsubscribe requests. Adds to suppression_list with reason. Marks company as closed_lost. Blocks all future sends to that email/domain.

Feature Flags

Three flags from system_flags table: automation_enabled, send_enabled, imap_enabled. 10s cache. Fail-closed for safety.

Enrichment Safety

Guards against enriching: job boards, enterprise domains, media/social domains, companies with enterprise descriptions. Max attempts enforced.
