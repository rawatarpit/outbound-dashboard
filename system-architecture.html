🏗️ Harness Architecture — How Every Agent is Wrapped

Every agent goes through the same lifecycle managed by the harness layer (src/harness/). The harness provides: context assembly, memory injection, prompt building, structured LLM generation with Zod, retry/fallback, observability, and tool registration.

contextManager.tssrc/harness/contextManager.tsToken budget estimation, message truncation, context assembly (delegates to src/discovery/harness/contextAssembler.ts). assembleContext() fetches: similar companies (via vector similarity), past outcomes, source performance, enrichment history, intents, conversion patterns. buildContextPreamble() formats selected context blocks for injection into agent prompts.

promptBuilder.tssrc/harness/promptBuilder.tsbuildSystemPrompt() from AgentConfig (identity, objective, capabilities, constraints, output format). buildResearchPrompt(), buildQualificationPrompt(), buildOutreachPrompt() — stage-specific builders with sanitization via sanitizeForPrompt(). All use buildAgentPrompt() which composes compaction + context preamble + user message.
errorHandling.tssrc/harness/errorHandling.tswithRetry() — exponential backoff (base 1s, factor 2, jitter), max 3 attempts. withFallback() — primary + fallback function. isNonRetryable() — 400/401 errors. getErrorSuggestion() — per-tool human-readable suggestions. structuredError() — JSON error with tool name, message, input, suggestion.
observability.tssrc/harness/observability.tscreateRunId() — unique ID per agent turn. logAgentTurn() — pino-structured log with run_id, agent_id, turn, tokens, tools called, latencies, errors, cost, context utilization. Warns at >80% context or >2 tool errors.
toolRegistry.tssrc/harness/toolRegistry.ts14 tool definitions: scrape_website, generate_research (agent-handled), score_qualification (agent-handled), generate_outreach (agent-handled), save_to_database (agent-handled), search_web, search_hackernews, search_y_combinator, enrich_company_forge, scrape_extract_company, extract_content_seeds, search_ddg, search_searxng, search_meta_ads, search_maps. Each has Zod schema + executor. Python scripts called via execFile with 180s timeout.
adapterTools.tssrc/harness/adapterTools.ts9 adapter-specific tools: search_reddit, search_pushshift, search_indeed, search_jobs, search_news, search_wellfound, search_linkedin, search_meta_ads, search_maps. Wraps actual adapter implementations. getAdapterToolsBySource() maps source name → tool.
types.tssrc/harness/types.tsCore interfaces: ToolDefinition, ToolCall, ToolResult, AgentTurnLog, ContextBudget, AgentConfig, AgentResult<T>, AgentResultStatus enum (SUCCESS/RETRYABLE_FAILURE/TERMINAL_FAILURE/SKIPPED)
contextAssembler.ts (src/discovery/harness/contextAssembler.ts) — the most complex harness module. For each agent call, it runs 5 parallel queries:
findSimilarCompanies() vector search via match_discovery_embeddings RPC (threshold 0.6, returns top 5). Falls back to seed companies (Vercel, Retool, Airbyte) if none found.
findRelevantIntents() — active brand intents ordered by priority
findPastOutcomes() — last 100 companies by status (closed_won/rejected), computes avg score
findSourcePerformance() — signal_source_performance table
findEnrichmentHistory() — discovered_companies by domain
Plus buildCompaction() — stage-dependent: qualification+ stage fetches research; outreach+ adds qualification; reply+ adds outreach; negotiation adds reply.

📝 Harness Prompt Building — Stage by Stage
AgentPrompt templateKey instructionsIdentity enforcement
Research buildResearchPrompt() "You are conducting strategic research for {brand}. Analyze this company website content. Return JSON: industry, size_estimate, pain_points, buying_signals..." Brand name, positioning, core offer, audience injected at top
Qualification buildQualificationPrompt() "You are qualifying a lead for {brand}. Return ONLY valid JSON: fit_score (0-100), reasoning (string, NOT array), confidence (0-1)" Brand offer, industry, pain points, automation maturity, buying signals
Outreach buildOutreachPrompt() "You are {sender}, founder of {brand}. CRITICAL IDENTITY RULES: Do NOT say 'we developed {company}' — you are selling TO them, not representing them. Write personalized cold email under 150 words." Sender name + founder identity explicitly guarded against role reversal. Recipient name used naturally. Falls back to "there" if no name.
All prompts go through: buildAgentPrompt({ systemPrompt, contextPreamble, compaction, userMessage }) which composes the final prompt as: compaction block (past research/scores/drafts) → context preamble (similar companies, outcomes, source perf) → user message (stage-specific instructions).
